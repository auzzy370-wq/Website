Implementation notes

Built as HTML, CSS, and JavaScript.

This version uses CDN-hosted Three.js, OrbitControls, GSAP, and Chart.js. It avoids a build system so it can be opened directly or hosted on any static server.

Read setup guide

Production upgrade path

  1. Replace procedural avatars with optimized GLB models in assets/models.
  2. Add KTX2 texture compression and Draco mesh compression for faster loading.
  3. Connect pose estimation to MediaPipe, MoveNet, or a server-side computer vision pipeline.
  4. Move localStorage records to authenticated user profiles when backend work begins.
